# Rubric for "Authorization" Task

**Maximum Points: 100**

### Criteria

1. **Project Setup and Dependencies (20 points)**
   - Proper setup of the Maven or Gradle project with all necessary dependencies.
   - The project should be correctly structured and ready for development.

   - *20 points*: All dependencies are correctly included, and the project is well-structured.
   - *10-19 points*: Minor issues with dependencies or project structure.
   - *0-9 points*: Significant issues with dependencies or project structure, affecting progress.

2. **Client Implementation for Obtaining Tokens (40 points)**
   - Correct implementation of the client to obtain bearer tokens using the client credentials grant type.
   - Proper use of the singleton pattern for managing the client.

   - *40 points*: Client is correctly implemented, following best practices, and uses the singleton pattern effectively.
   - *20-39 points*: Minor issues in implementation or singleton pattern usage.
   - *0-19 points*: Major issues in client implementation or failure to use the singleton pattern correctly.

3. **Handling of Different Scopes (25 points)**
   - Correct handling of obtaining and using bearer tokens with both read and write scopes.

   - *25 points*: Bearer tokens are correctly obtained and handled for both read and write scopes.
   - *13-24 points*: Minor issues in handling one or both scopes.
   - *0-12 points*: Significant issues or failure to handle different scopes correctly.

4. **Review and Usage of Swagger Documentation (15 points)**
   - Proper review and understanding of the Swagger documentation for API endpoints.

   - *15 points*: Full understanding and correct usage of Swagger documentation.
   - *8-14 points*: Minor gaps in understanding or usage.
   - *0-7 points*: Failure to review or use Swagger documentation effectively.
